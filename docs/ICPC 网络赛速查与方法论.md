# 第一部分：解题方法论

## 一、总流程：拿到题先做什么

1. **读题三问**
* 输入是什么结构？序列、树、图、字符串、几何、多组？
* 输出是什么？数、方案、最值、构造、判定、交互？
* 约束是什么？$n$ 多大，值域多大，多测几组？


2. **形式化**
* 把题面翻译成：给定 $A$，求 $B$，满足 $C$。
* 用样例验证理解，特别看边界样例。


3. **定复杂度**
* 由 $n$ 反推允许的复杂度。
* 先想暴力，再想优化。


4. **找模型**
* 这是序列问题？树？图？集合？字符串？数学？
* 等价转换：能不能转成最短路、匹配、流、DP、计数？


5. **选算法**
* 按“问法”和“模型”匹配常用套路。
* 优先想：二分、DP、贪心、图论、数据结构、数论。


6. **写与调**
* 先写暴力/朴素，再优化。
* 样例 → 边界 → 对拍 → 提交。

## 二、数据范围反推复杂度

| $n$ 范围 | 允许复杂度 | 常见算法 |
| --- | --- | --- |
| $n \le 10$ | $O(n!)$ | 搜索、全排列 |
| $n \le 20$ | $O(2^n \cdot n)$ | 状压 DP、折半搜索 |
| $n \le 100$ | $O(n^3)$ | Floyd、区间 DP、高斯消元 |
| $n \le 500$ | $O(n^2)$ | 普通 DP、二分图匹配 |
| $n \le 5000$ | $O(n^2)$ | 同上，注意常数 |
| $n \le 10^5$ | $O(n \log n)$ | 排序、线段树、最短路、树剖 |
| $n \le 10^6$ | $O(n)$ | 线性 DP、双指针、前缀和 |
| $n \le 10^9$ | $O(\log n)$ | 二分、矩阵快速幂、数论 |
| $n \le 10^{18}$ | $O(\log n)$ | 快速幂、exgcd、矩阵 |

> 多测时，总复杂度要乘 $T$。网络赛留 3 ~ 5 倍常数余量。

## 四、模型识别：看到什么想什么

### 序列

* 区间和 / 区间修改 → 前缀和、差分、树状数组、线段树。
* 子数组最值 → 单调栈、单调队列、ST 表。
* 最长上升子序列 → LIS $O(n \log n)$。
* 双指针 → 单调性、计数、滑窗。

### 树

* 路径查询 → LCA、树剖、树上差分。
* 子树查询 → DFS 序 + 树状数组 / 线段树。
* 连通性 → 并查集、DFS。
* 换根 → 换根 DP。
* 基环树 → 拓扑找环，断环处理。

### 图

* 最短路 → Dijkstra / SPFA / Floyd。
* 连通块 → DSU / BFS / DFS。
* 有向无环 → 拓扑排序 + DP。
* 强连通 → Tarjan。
* 二分图 → 匹配、König、霍尔。
* 覆盖 / 独立集 / 路径覆盖 → 最大匹配。
* 最大流 / 最小割 → Dinic。
* 费用 → 费用流。
* 生成树 → Kruskal / Prim / 矩阵树。

### 集合

* 子集枚举 → 状压 DP。
* 异或最值 → 线性基。
* 动态连通 → 并查集。

### 字符串

* 匹配 → KMP、Z、哈希。
* 多模式匹配 → AC 自动机。
* 回文 → Manacher。
* 子串统计 → 后缀数组、后缀自动机。
* 防卡 → 双哈希 / 随机 base。

### 数学

* 同余方程 → exgcd、逆元、CRT。
* 组合计数 → 阶乘逆元、Lucas、容斥。
* 数论函数 → 莫比乌斯、欧拉函数。
* 线性递推 → 矩阵快速幂。
* 线性相关 → 高斯消元、线性基。

## 五、DP 怎么写：五步法

1. **状态定义**
* 前 $i$ 个？选了 $j$ 个？当前在 $x$？当前值为 $v$？
* 状态要能覆盖所有影响转移的信息。


2. **转移**
* 从哪些状态来？到哪些状态去？
* 写出转移方程，检查是否漏情况。


3. **初始化**
* 空集、起点、0、INF。
* 多测清空。


4. **答案**
* 哪个状态是答案？最大 / 最小 / 求和？
* 注意取模和溢出。


5. **优化**
* 前缀和、单调队列、斜率优化、四边形不等式、矩阵快速幂。



---

## 六、实现与调试步骤

1. **框架**
* 多测读入，清空数组。
* 定义常量、类型、INF。


2. **先写暴力**
* 小数据能过样例，用来对拍。
* 不要一上来就写复杂优化。


3. **再写正解**
* 模块化：读入、建图、预处理、核心、输出。
* 边写边想边界。


4. **检查清单**
* 多测清空？数组大小？`long long`？取模负？$n=0/1$？空集？重边？自环？输出格式？交互 `flush`？


5. **对拍**
* 随机小数据，暴力 vs 正解。
* 打表找规律，验证猜想。



---

## 七、赛时策略

* 先扫题，签到，跟榜。
* 多开：一题卡住，换另一题。
* 5 分钟无思路，先写暴力或打表。
* 能贪心先猜，能二分先二分，能 DP 先想状态。
* 不要死磕，网络赛拼题量和罚时。
* 提交前默念：清空、开大、long long、取模、边界。

# 第二部分：常用结论速查

## 数论 / 组合

* $\gcd(a, b) \operatorname{lcm}(a, b) = a \cdot b$，计算 `lcm = a / gcd * b` 防溢出。
* 逆元：
* $p$ 为质数：$a^{-1} \equiv a^{p-2} \pmod p$
* 任意模数（互质）：$\operatorname{exgcd}(a, m, x, y)$
* 线性逆元：`inv[i] = 1ll * (p - p / i) * inv[p % i] % p`


* 扩展欧拉定理：若 $b \ge \varphi(m)$，则：

$$a^b \equiv a^{b \bmod \varphi(m) + \varphi(m)} \pmod m$$


* Lucas 定理：$p$ 为质数时：

$$\binom{n}{m} \equiv \binom{n \bmod p}{m \bmod p} \binom{\lfloor n/p \rfloor}{\lfloor m/p \rfloor} \pmod p$$


* $\binom{n}{m}$ 为奇数 $\iff (n \ \& \ m) = m$。
* 卡特兰数：

$$C_n = \frac{1}{n+1} \binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n-1}$$


* 错排：$D_n = (n-1)(D_{n-1} + D_{n-2})$，边界 $D_1 = 0, D_2 = 1$。
* 斐波那契：$\gcd(F_m, F_n) = F_{\gcd(m, n)}$。
* 约瑟夫环：$J(n, k) = (J(n-1, k) + k) \bmod n$（编号从 $0$ 开始）。
* 莫比乌斯反演：$[\gcd(i, j) = 1] = \sum_{d \mid \gcd(i, j)} \mu(d)$。
* 整除分块：$r = \left\lfloor \frac{n}{\lfloor n/l \rfloor} \right\rfloor$。
* 线性基：最大异或从高位贪心；第 $k$ 小先重构，注意 $0$ 能否表示。
* 矩阵树：无向图生成树数 $=$ Laplacian 矩阵去一行一列的行列式值。
* 高斯消元：异或方程组、行列式、线性相关判定。

---

## 图论 / 网络流

* 最短路：
* 非负权：Dijkstra
* 负权：SPFA / Bellman-Ford
* 全源闭包：Floyd


* 拓扑排序判 DAG；Tarjan 求强连通、割点、桥、边双、点双。
* 2-SAT：
* 边 $x \to y$ 表示选 $x$ 则必须选 $y$。
* 若 $x$ 与 $\neg x$ 在同一 SCC，则无解。
* Tarjan 缩点后，通常选拓扑逆序靠前（SCC 编号更小）的文字。


* 二分图：
* 最大匹配
* König 定理：最小点覆盖 $=$ 最大匹配
* 最大独立集 $= n -$ 最大匹配
* 最小边覆盖 $= n -$ 最大匹配
* DAG 最小路径覆盖 $= n -$ 拆点后二分图最大匹配


* 网络流：
* 最大流 $=$ 最小割
* 最大权闭合子图 $=$ 正权和 $-$ 最小割
* Dinic 记得当前弧优化


* 费用流：负权 SPFA，或势能 Dijkstra。
* 欧拉回路：
* 无向图连通且奇度点数为 $0$（回路）或 $2$（路径）。
* 有向图弱连通且每个点入度等于出度（回路），或仅起终点度数差为 $1$（路径）。


* 树：
* 直径：两次 DFS / 树形 DP。
* 重心：最大子树大小最小。
* LCA：倍增 / 欧拉序 RMQ。


* 树上差分：
* 点差分：$d[u]++,\ d[v]++,\ d[\operatorname{lca}]--,\ d[fa[\operatorname{lca}]]--$
* 边差分：$d[u]++,\ d[v]++,\ d[\operatorname{lca}] -= 2$


* 基环树：拓扑找环，断环处理。

---

## 字符串

* KMP：$nxt$ 为最长 border；最小周期 $n - nxt[n]$（当且仅当 $n \bmod (n - nxt[n]) = 0$）。
* Manacher：$d_1$ 奇回文半径，$d_2$ 偶回文半径。
* Z 函数：$z[i] = \operatorname{LCP}(s, s[i..])$。
* 哈希：子串哈希值公式：

$$h[l..r] = h[r] - h[l-1] \cdot base^{r-l+1}$$



建议双模或随机 base 防 hack。
* AC 自动机：fail 树子树和 $=$ 模式串出现次数。
* 后缀数组：$\operatorname{lcp}(i, j) = \min(height[i+1..j])$。
* 后缀自动机：本质不同子串数：

$$\sum (len[i] - len[link[i]])$$

## 数据结构

* 树状数组：`lowbit(x) = x & (-x)`；利用差分可做区间加、区间和。
* 线段树：懒标记、动态开点、权值线段树、线段树合并总复杂度 $O(n \log n)$。
* 并查集：路径压缩 + 按秩合并；扩展域 / 带权维护到根距离。
* ST 表：$O(1)$ 查询 RMQ。
* 单调栈：左右第一个更大 / 更小；单调队列优化 DP。
* 莫队：块大小 $n / \sqrt{q}$，偶数块倒序排序。
* 主席树：静态区间第 $k$ 小。
* 树剖：路径查询、修改、LCA；DSU on tree 离线统计子树信息。

---

## DP / 杂项

* 01 背包倒序，完全背包正序，多重背包二进制拆分 / 单调队列优化。
* LIS $O(n \log n)$：严格递增用 `lower_bound`，非降用 `upper_bound`。
* 数位 DP：记忆化搜索 `(pos, limit, lead, state)`。
* 状压枚举子集：
```cpp
for (int s = mask; s; s = (s - 1) & mask)

```


* 期望线性；概率正推，期望倒推。
* 矩阵快速幂优化线性递推；斜率优化维护凸包；四边形不等式判定决策单调。
* 二分答案，三分凸函数，离散化，前缀和 / 差分。
* 最大子段和 Kadane 算法；绝对众数摩尔投票；区间调度按右端点贪心。
* 霍尔定理：二分图存在完美匹配 $\iff$ 对任意左侧点子集 $S$，均有 $\vert{}N(S)\vert{} \ge \vert{}S\vert{}$。
* Dilworth 定理：最小链覆盖数 $=$ 最长反链长度。

## 博弈 / 几何

* Nim 博弈：异或和非零先手必胜。
* 反 Nim：全为 $1$ 看堆数奇偶；否则同 Nim。
* SG 函数：$\operatorname{mex}$ 运算，多游戏独立异或和。
* 巴什博弈：$n \bmod (m+1) \neq 0$ 先手胜。
* 威佐夫博弈：奇异局势公式：

$$\left(\lfloor k\varphi \rfloor, \lfloor k\varphi^2 \rfloor\right), \quad \varphi = \frac{1+\sqrt{5}}{2}$$


* 叉积判左右，任意多边形面积等于顶点叉积和除以 $2$。
* 凸包 Andrew 算法，旋转卡壳求直径。
* 皮克定理：$S = I + B/2 - 1$。
* 浮点比较写 `eps`，能使用整数几何就避免浮点运算。

## 常用内置函数 (GCC)

* `__builtin_popcount(x)`：`unsigned int` 二进制中 $1$ 的个数。
* `__builtin_popcountll(x)`：`unsigned long long` 版本。
* `__builtin_ctz(x)`：末尾 $0$ 的个数，`x = 0` 时未定义。
* `__builtin_clz(x)`：前导 $0$ 的个数，`x = 0` 时未定义。
* `__builtin_ffs(x)`：最低位 $1$ 的位置（从 1 开始），`x = 0` 返回 0。
* `__builtin_parity(x)`：$1$ 的个数的奇偶性。
* `std::__lg(x)`：求 $\lfloor\log_2 x\rfloor$，相当于 `31 - __builtin_clz(x)`。
* `__builtin_sqrt` 等不保证存在，建议使用 `<cmath>` 中的 `sqrt` / `sqrtl`。
