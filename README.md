# 算法竞赛题解与模板代码库 (Competitive Programming Repository)

本仓库汇总了个人的算法竞赛（ICPC / CCPC / 百度之星 / Codeforces / AtCoder / 洛谷 / 牛客）训练题解、可复用模板库以及备赛笔记。

---

## 📂 仓库结构概览

```text
.
├── templates/              # 分类算法模板库 (按板块分类，含 C++ 与 Python 双版本)
│   ├── basic/              # 基础工程缺省源、快速IO、离散化、二维前缀和
│   ├── data_structures/    # 并查集、树状数组、线段树、字典树、01-Trie、线性基
│   ├── math/               # 自动取模类、组合数学、扩展欧几里得、素数筛、高精度
│   ├── graph/              # 最短路 Dijkstra、动态树直径
│   ├── strings/            # KMP 字符串模式匹配、回文生成
│   └── README.md           # 模板模块详细索引与复杂度速查
├── docs/                   # 比赛笔记、方法论与开发环境配置
│   ├── ICPC 网络赛速查与方法论.md
│   ├── 博弈-最小循环移位排列-The_Game.md
│   └── NVIM_GUIDE.md
├── 算法模板.md             # 算法竞赛全专题通用大纲手册 (包含理论、推导与 55+ 核心代码块)
├── CF/                     # Codeforces 比赛与题目题解
├── Atcoder/                # AtCoder 比赛与题目题解
├── luogu/                  # 洛谷历年真题与训练题解
├── nowcoder/               # 牛客小白月赛、周赛与多校联赛题解
└── cwnu_oj/ & ctgu_oj/     # 高校 OJ 训练题解
```

1. **[算法模板库索引 (Templates Index)](templates/README.md)**：包含各板块独立代码文件的功能速查表与调用说明。
